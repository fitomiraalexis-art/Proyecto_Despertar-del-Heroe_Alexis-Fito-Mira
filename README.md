# El despertar del héroe

## Descripción del proyecto

El despertar del héroe es un proyecto individual desarrollado en Java para el ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM), correspondiente a la primera evaluación.

El proyecto consiste en crear un juego de aventura por turnos que se ejecuta en consola. El jugador deberá crear un héroe y enfrentarse a tres enemigos de dificultad creciente, gestionando sus puntos de vida y el uso de pociones durante los combates.

## Objetivos

El objetivo principal es aplicar los conocimientos adquiridos en programación mediante el desarrollo de una aplicación funcional. Para ello, se trabajará con variables, constantes, estructuras condicionales, bucles, métodos estáticos y arrays.

También se implementarán mecanismos de validación de datos, un sistema de puntuación y un ranking que permita conservar los resultados de las partidas.

## Funcionamiento

La aplicación contará con un menú principal que permitirá iniciar una nueva partida, consultar el ranking, acceder a la ayuda y salir del programa.

El héroe comenzará con 100 puntos de vida y tres pociones que recuperarán 25 puntos de vida cada una. Sus ataques causarán entre 10 y 20 puntos de daño, mientras que los enemigos tendrán 40, 60 y 80 puntos de vida, respectivamente, y causarán entre 5 y 15 puntos de daño.

La aventura finalizará cuando el jugador derrote a los tres enemigos, pierda toda su vida o decida abandonar la partida. Cada enemigo derrotado otorgará 100 puntos y, en caso de completar la aventura, se añadirá como bonificación la vida restante del héroe.

## Tecnologías y herramientas

El lenguaje de programación utilizado será Java. El desarrollo se realizará en Visual Studio Code y se empleará Git para el control de versiones y GitHub para alojar el repositorio y registrar la evolución del proyecto. El formato XML se utilizará para conservar el ranking entre partidas.

## Pruebas y seguimiento

Durante el desarrollo se realizarán pruebas para comprobar el funcionamiento de los menús, los combates, el inventario, el sistema de puntuación y el ranking. También se comprobará el tratamiento de entradas incorrectas y otras situaciones que puedan producir errores.

Los cambios se registrarán mediante commits con mensajes descriptivos, permitiendo consultar el historial de desarrollo del proyecto.

## Estado del proyecto

El proyecto se encuentra en desarrollo. Las funcionalidades se implementarán y comprobarán progresivamente de acuerdo con los requisitos establecidos para la evaluación.
